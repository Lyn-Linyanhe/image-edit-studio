# 图片风格提取模板组（图生图专用）

> **只用一条就够？** 用 `compose/style_prompt_final.md` 里的最终版完整提示词。
> 本文件是分场景模板组，用于批量、JSON、多图统一、追问纠错等具体情形。

> 用途：从一张参考图提取"可迁移的风格"，喂给 img2img（gpt-image /images/edits、SD/Flux 图生图等）。
> 原则：**只搬风格，不搬内容**。主体、构图、物体位置由原图提供，风格词只负责媒介/光影/色彩/质感。
> 占位符：`{图片}` 参考图，`{目标}` 要改的原图，`{强度}` 图生图强度。

---

## T1 · 主模板：完整风格提取（推荐默认用这个）

```
你是一位图像风格分析师。分析我提供的参考图 {图片}，目标是把它的"风格"迁移到另一张图上。

严格按以下 11 项输出，每项一行标签化短语，不要写散文、不要客套：

1. 媒介与技法：          （摄影/油画/水彩/3D渲染/像素/矢量/动画赛璐璐…）
2. 画面笔触与边缘：      （硬边/软边、厚涂、光滑、线稿感…）
3. 色彩方案：            （主色 3 个 + hex、辅色、点缀色；饱和度/明度对比高低）
4. 光影：                （光源方向、软硬、体积光/轮廓光/环境光遮蔽、阴影色）
5. 质感与颗粒：          （噪点、胶片颗粒、纸张纹理、SSS、金属度…）
6. 景深与镜头感：        （广角/长焦、浅景深、虚化程度、眩光/暗角）
7. 细节密度：            （近景堆细节还是整体概括、纹理丰富度）
8. 风格归属：            （像哪个流派/年代/艺术家/作品系列）
9. 情绪与氛围：          （1–3 个词）
10. 可迁移风格标签：     （英文，逗号分隔，≤15 个，按重要性从高到低排序）
11. 负向标签：           （英文，列出这张图明显"没有"的风格特征，逗号分隔）

【硬性约束】
- 第 10 项禁止出现具体物体、人物、场景名词（不要 "girl" "forest" "city"），只能是风格维度词。
- 第 10 项词序 = 我认为的权重顺序，最有辨识度的排最前。
- 若某项判断置信度低，在该项末尾加 "（不确定：原因）"。
- 全部输出用中文说明 + 第 10/11 项用英文标签，方便直接复制进 prompt。
```

## T2 · 精简模板：只要 prompt 串

适合批量、省 token。

```
看这张参考图 {图片}。只做一件事：输出可迁移的风格 prompt。
要求：
- 英文，逗号分隔，12–18 个标签，按权重降序
- 只含媒介、光影、色彩、质感、氛围，不要任何物体/人物/地名
- 再输出一行 Negative: 后面的负向标签
- 不要解释，不要编号，不要 markdown
```

## T4 · 最终 img2img prompt 组装模板（把 T1/T2/T3 结果套进来）

```
使用参考图 {图片} 的风格，重绘 {目标}。

【必须保留】{目标} 的主体形态、构图、物体位置、画面内容完全不变。
【只改变】风格：媒介、笔触、光影、色彩、质感、氛围。

正向 prompt：
[媒介与技法] {第10项前 4–6 个词}
[光影] {第4项}s
[色彩] {第3项}s
[质感] {第5项}s
[氛围] {第9项}
[画质底座] highly detailed, coherent lighting, consistent color grading

负向 prompt：
{第11项}, blurry, lowres, watermark, text, deformed, oversharpened halos

参数：
strength / denoise: {强度}
```

### 参数起点（需实测微调）

| 目标 | 强度起点 | 说明 |
|---|---|---|
| 只换色调光影 | 0.25–0.35 | 原图结构最稳 |
| 换画风（照片→插画） | 0.45–0.6 | 平衡点，最常用 |
| 大改风格仍保构图 | 0.6–0.75 | 结构开始漂移，需加 mask 约束 |

> **注意**：gpt-image-1 的 `/images/edits` 接口**没有 strength/denoise 参数**（只有 image、mask、prompt、n、size、quality），风格强度只能靠 prompt 措辞 + mask 范围控制。上表主要给 SD / Flux / ComfyUI 系用。

## T5 · 多图取交集：统一系列风格

画一组图要保持同一风格时用。

```
我提供多张参考图 {图片列表}。提取它们的**共同**风格：
1. 只保留在所有图中都出现的风格特征（媒介、光影、色板、质感）
2. 明确列出各图之间不一致、因此**不能**写进 prompt 的特征
3. 输出统一的英文风格 prompt（≤15 词）+ 负向标签
4. 额外给一段"风格锚定句"，用于每条 prompt 开头保持一致性
```

## T6 · 追问 / 纠错模板

- **串味了**（主体/场景被参考图带进来）：
  `你上一版 style_tags 里混进了内容词：{列表}。删掉它们，只保留纯风格维度词重新输出。`
- **风格不够强**：
  `加强第 3/4/6 项的描述颗粒度：色板给到 5 个以内的 hex，光影写明光源方向与软硬程度，并给出这些词的英文表达。`
- **太泛了**（出来像通用"好看图"）：
  `你给的词太通用。换成更有辨识度的具体媒介/流派术语（例如用 "gouache illustration with visible paper grain" 而不是 "artistic"），并说明每个词的来源依据。`
- **想要忠实复刻**：
  `保留原作者/作品指向的表述，并标注这是"风格指向"而非"内容复制"。`

## T7 · 负向词标准底座（每次都可带）

```
blurry, lowres, jpeg artifacts, watermark, signature, text, extra fingers,
deformed limbs, bad anatomy, oversaturated, harsh halos, plastic skin,
muddy colors, flat lighting, cluttered background
```

## 使用要点（踩坑清单）

1. **先问"哪些是内容、哪些是风格"**。跳过这步，img2img 十有八九会把参考图的主体搬过来。
2. **style_tags 里绝不能有名词**。出现 `forest`、`knight`、`sunset over sea` 就说明它在描述内容，直接删。
3. **词序即权重**。把最有辨识度的媒介词放最前，通用画质词放最后。
4. **主色不要超过 3–4 个**。色板词太多会互相稀释，最后出来一锅灰。
5. **冲突词会互相抵消**：`soft lighting` + `harsh shadows`、`minimal` + `highly detailed` 同时出现等于噪声。
6. **中文标签对多数生成模型无效**，第 10 项务必让模型给英文。
7. **结果要可证伪**：拿提取出的 prompt 对同一张原图重跑一次，看是否真的接近参考图风格；不接近就说明词太泛，回到 T6 追问。
8. **一次只调一个变量**：先定风格词，再调强度，最后调色板——三个一起改，出问题查不出原因。
