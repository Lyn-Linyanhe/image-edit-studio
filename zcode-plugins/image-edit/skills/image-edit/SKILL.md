# 改图（人手涂抹）

用户要改图时：**先打开本地画布，让人涂，不要替他指定区域。**

ZCode 没有侧栏按钮。完整功能在本地页 `http://127.0.0.1:8000/`。本插件只负责把服务拉起来并打开浏览器。

## 必做步骤

1. 调用 MCP `image_edit_open`（内部会先 ensure）。
2. 把返回的 URL 发给用户，明确说：在图上涂要改的区域，填 Base URL / API Key / 模型 / 提示词，再点提交。
3. **禁止**根据用户一句话去猜 bounding box、生成黑白遮罩、或整图重画来「代替涂抹」。除非用户明确说「整图重画、不用遮罩」。
4. **禁止**向用户要 API Key 再经对话转发。密钥只存在浏览器 localStorage。

若只要状态：`image_edit_status`。若要停掉：`image_edit_stop`。服务起不来时读插件目录里的 `server.log`。

## 页面能力（与原 DSH 挂件对齐）

- 内容图：选文件 / 追加 / 复制遮罩 / 清空列表
- 画布：画笔 / 橡皮 / 清空 / 反选 / 适应窗口。涂抹区 = 要改的区域；反选 = 涂哪保哪
- 参考图：可多张，按角色标签挂
- 引擎：默认 GPT（`gpt-image-2`）；作用域「整图」或「仅遮罩区」
- 接口：Base URL（到 `/v1`）、API Key（可切明文）、测试、获取模型列表
- 参数：模型、提示词、质量、分辨率

## 上游协议（本地服务已经替用户做了）

- `/images/edits` 的 `mask` 字段会被静默忽略。真正生效的是：把要改的区域硬涂纯红作为 `image[1]`，提示词里说明「红色只是标记」。
- **仅遮罩区**：只发涂红图（不发干净原图）。把干净原图一起发，模型会照抄把那块「恢复」。
- **整图**：不涂红，发缩放后的原图。
- 投喂用 JPEG（约 q88），体积由目标尺寸决定；大约 1.96 MiB 通过、2.12 MiB 起被拒。
- 尺寸不严格：请求 `1024x1536` 可能回 `1029x1528`。不要做像素级对齐。
- `HTTP 502 Upstream access forbidden` 是瞬时上游故障，让用户重试，不要当坏请求去改代码。
- 账号可能只暴露一个模型，列表只有一条不是 bug。

适合「这块清掉重画」（换背景、重画道具）。不适合「保留结构再整体调色」——红标会抹掉该区域原信息。

## 本机约束

- 只监听 `127.0.0.1`，无鉴权。不要暴露到公网。
- 需要本机 Python 3.10+ 与 Pillow。MCP 用 `python3` 拉起 `server/mask_edit_app.py`。
- 依赖 OpenAI 兼容的 `POST {base}/images/edits`。没有这个端点就只剩文生图，局部改图不可用。
