# r2 · 路线②：头部不动，只把身体改成抱书

**路线**：保留目标图原来的**头部朝向与视线**（回望观者、头微低），只把**锁骨以下的身体**改成"双手抱书"。
头部不转动 → **头部区域可以用低 denoise / mask 保住**，脸、发、花、星饰、X 发夹、羽毛、蓝眼、小痣全部来自原图像素。

**代价**：拿不到 `187D` 的"头朝右上微仰"。
**收益**：辨识度大幅保住——r1 丢掉的东西**全在头上**（见下表）。

## r1 为什么失败（诊断依据）

| 蓝像素总量 | 0.233% | 0.027% | 掉 8.6 倍 |
| 三朵长尖瓣花 | 3 朵 · **画面右侧** | 1 朵圆瓣 · **画面左侧** | 放大核对 |
| 白色星形发饰 | 左侧 3–4 枚 | **消失** | 放大核对 |
| 小痣 | 右眼下 1 颗 | 眼下 2–3 个点 | 放大核对 |
| 袖子 | 无袖 | **多了长蕾丝袖** | 放大核对 |

根因：`187D` 同时供"画法 + 姿态"，姿态要求重绘头部 → 整颗头被替换成参考图先验。
**本版把头部从"重绘区"里拿出来**，问题从根上消失。
