## 6. 这一版的风险（按严重度）

1. **银灰发漂移（本版最高风险）**：基准图 `187D` 是**银灰浅发**，与你目标图**同为浅发**，
   而本版又让它同时承担"姿态"——模型对它的依赖权重更高，收敛到"银灰发抱书少女"的概率显著上升。
   → 三道防线都开着：`COLOUR IDENTITY LOCK` 段 + `DO NOT TAKE FROM THE FIRST IMAGE` 里点名"silver-grey hair"
   + 出图后跑 `preserve_hue.py --sat-scale 1.0`。
2. **手部崩坏**：目标图原本没有手，这是**凭空新增**的双手 + 书本，属于最容易画坏的部分（手指数量、关节）。
   → 重跑时优先挑手画得对的那张，别为了风格浓度牺牲手。
3. **姿态与发饰位置的耦合**：头一转，花、星形发饰、X 发夹、羽毛耳饰的位置全部要跟着重新排。
   模型很可能把它们留在原来的画面位置（变成飘在空中的贴纸）。→ prompt 里已写 *following the head*；
   出图后逐项核对这四处。
4. **书的颜色**：已指定用目标图自己的暖灰橄榄色（不是基准图的鼠尾草绿）。要换就删掉那一段。
5. **背景与人物轮廓的匹配**：人物转体后，原来的背景结构可能出现"人物移开了、背景没跟上"的错位感。
   → 若明显，改为让背景也做小幅重排，或降低背景细节使其更抽象（这仍属方案一允许的"简化"）。
6. **裁切变化带来的比例**：下缘下移后画面重心会变，人物占比变小。若你想保持原来的人物大小，
   就得同时放宽左右的留白——这一步会明显改动构图，属于你在本版已经接受的代价。

3. `quality=high`，`n=1` 起，建议出 **4 张**选优（本版难度高于上一版）。
