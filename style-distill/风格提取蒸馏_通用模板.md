# 风格提取 / 蒸馏 · 通用模板（填槽即用）

> **这是什么**：把「提取」与「蒸馏」两种用法收进同一份**可填空模板**的文件。
> 填 6 个槽位，选一个模式，复制对应段落即可。
>
> **先说最重要的一条结论**：
> **"提取"可以纯靠提示词；"蒸馏"不行。** 蒸馏 = **模型做定性 + 脚本做定量 + 参照法做证伪**，三者缺一不可。
> 因为模型给不出"最暗像素 0.166–0.320""纯白占比 0.446–0.624"这种数字，而本仓库实测恰好证明——
> 真正能把风格分开的正是这些数字，不是形容词（"低饱和"的异风格图 0.077 夹在本风格 0.035 与 0.144 之间，
> 见 `漫画风格蒸馏.md` 第 233–245 行）。所以任何"让模型直接吐出风格阈值"的模板都是错的。
>
> **配套**（各一份，互不重复正文）：
> **新任务请从 `风格蒸馏_通用流程.md` 进**（阶段顺序 · 产物 · 门禁 · 返工矩阵）；本文件是流程里
> 阶段 1/2/4/5 用的**可粘贴提示词与槽位**；
> `风格提取提示词_v2.md`（模式 A 的权威正文）、`风格提取提示词_评审.md`（为什么这么设计）、
> `漫画风格蒸馏.md` + `style_card.json`（模式 B 的一次真实执行结果）。

## 0. 槽位（只填这 6 个，其他都不用改）

| 槽位 | 含义 | 用到它的模式 | 填法要点 |
|---|---|---|---|
| `{图片}` | 单张参考图 | A | 风格来源，只提供手法 |
| `{图片组}` | **同风格**多张参考图 | B | 建议 ≥6 张，且尽量覆盖该风格的"最淡/最艳"两端（同一风格内部饱和度实测跨度可达 0.032–0.148） |
| `{目标图}` | 要改的那张图 | A（可选）、C | 内容来源；没有它就只做提取 |
| `{档位}` | `方案一` 保内容与构图 / `方案二` 连构图迁移 | A、C | 默认方案一 |
| `{强度}` | 保守 / 平衡 / 强 | A、C | 默认平衡 |
| `{接口}` | edits 类（无 denoise/无独立负向通道）/ 纯文生图 | A、C | 决定参数段怎么读，与提示词本体无关 |
| `{异风格参照图}` | 一张**明显不同**风格的图 | B | 只用于"参照法证伪"，不进任何 prompt |

## 3. 模式 B · 蒸馏（多图 → 风格规范卡）★ 本模板的主体

### 3.1 蒸馏的三层分工（先记住这张表，再动提示词）

| 层 | 谁做 | 做什么 | 不许做什么 |
|---|---|---|---|
| **定性** | 模型 | 媒介与技法判定、手法/内容裁决、标签措辞、风险与代价、情绪→视觉手法映射 | 不许猜作者/年代/模型/镜头；不许把"看起来像"写成结论 |
| **定量** | **脚本** | 留白占比、最暗值下限、明度、饱和度、对比跨度、笔触密度、色相族、色温 | **模型不许自己估算任何数字**（估出来的一律视为编造并作废） |
| **证伪** | 参照法 | 拿 `{异风格参照图}` 一起量，作废无判别力的指标 | 不许跳过；不证伪的阈值等于没有阈值 |

### 3.2 蒸馏提示词（可粘贴）

```
【角色】
你是图像风格分析师。我在做"风格蒸馏"：从一组同风格图片里提炼出一份可复用的风格规范，
供后续把别的图改成这个风格时使用。你的产出是**定性骨架**，所有数字由我随后用脚本实测填入。

【输入】
- 参考图组：{图片组}（同风格，请逐张看）
- 迁移档位：{档位}，默认方案一
- 目标接口：{接口}

【四条铁律（违反即视为失败）】
R1 只迁移手法，不迁移配色。这组图的具体色相、色板、hex 不得成为迁移目标；
   改图时目标图每个元素自己的颜色保持原样，暗部与高光从各元素自身色相派生。
R2 只搬风格，不搬内容。
R3 **禁止编造数字**。任何定量指标只写"指标名 + 待脚本实测"，不要给出你估算的值；
   看不出的写"未识别（原因）"；不得把推测的作者、年代、模型、镜头参数、制作流程写成事实。
R4 不确定就标出来，不要用"高级感""氛围感强"这类无效词补齐。

【任务】严格按 B-1 … B-9 九段输出。

=== B-1 共同手法 ===
只保留**在所有图里都出现**的技法与手法特征（媒介、线稿、边缘、色彩处理手法、光影逻辑、
材质、细节密度策略、构图手法类倾向）。每条后面附「出现张数」与「依据」。
给出 2–3 句话的一句话风格定义。

=== B-2 不一致项清单（不得写入 prompt）===
逐条列出各图之间有差异的特征，并注明：
① 出现在哪几张；② 属于"内容差异"还是"手法差异"；③ 为什么不能写进 prompt。

=== B-3 风格规范卡（结构化，字段名保持英文）===
style_id / one_line / source（张数·分辨率·画幅·一致性）
transfer_scope{rule, transferable[], not_transferable[]}
medium{category, technique, not[], finish, volume_shading}
subject / composition / palette（仅作描述性证据） / color_metrics / lighting / texture / mood
hard_constraints[] / transfer_recipe{} / acceptance_checklist[]
上述字段名与既有的 style_card.json 保持同名同义，便于直接替换。
discrimination_test{method, results, conclusion, do_not_verify_by} 与 artifacts 两段**留空**——
它们由第 3.3 节的脚本测量与参照法之后填入，不要在这里编。

=== B-4 可迁移风格标签 ===
英文，≤15 个，权重降序。禁止内容名词；禁止 hex 与色板名（muted palette / pastel palette 一类）。
表达色彩处理只用"手法语言"，例如 saturation reduced to a very low level while preserving
every element's own hue。

=== B-5 负向守卫 ===
必含 7 个：hue shift, recolouring, palette swap, wrong hair colour,
colour cast toward a different hue family, monochrome conversion, full greyscale
再给"按需追加"一组（防风格没上到位）。并按档位分流：
方案一（保目标图背景）一律剔除 detailed background / room / scenery 这类背景清除词——
负向区分不了"不要新增"和"删掉已有的"。

=== B-6 定量阈值（只给指标名与含义，数值留空）===
逐行给出这张风格卡需要哪些定量指标，每行格式：指标 | 脚本字段名 | 含义 | 用它验收什么
至少覆盖：留白占比、最暗值下限、整体明度、饱和度、对比跨度、笔触密度、色相族占比。
**数值一律写"待实测"，不要填任何你估计的数字。**

=== B-7 判别力待验证清单 ===
列出你认为最可能把本风格与别的风格分开的 3 个指标，并写明要用 {异风格参照图} 怎么证伪：
凡是参照图与本风格数值接近的指标，就作废。同时列出"已知外观印象型、很可能没有判别力"的指标。

=== B-8 不可迁移清单 ===
按四类写：🔵 手法 / 🟠 内容 / 🟡 半风格（附代价）/ 🔴 不可迁移（身份特征、作者署名、水印）。
其中"留白比例 / 背景处理 / 画幅景别 / 整体明暗档位 / 署名与水印"五项必须各自单独出现。

=== B-9 低置信项 ===
逐条列出你判断不确定的地方及原因，不要省略。

【自检】逐条 yes/no，答 no 说明如何修正：
1. B-6 是否完全没有出现具体数字？
2. B-4 是否不含内容名词、hex 与色板名？
3. B-2 是否覆盖了各图之间所有主要差异？
4. B-8 的五项是否都单独出现并判了归属？
5. 是否存在违反 R3 的编造？
```

### 3.3 蒸馏的量化步骤（命令按本仓库真实 CLI）

```powershell
# ① 先自检 Lab 实现（本仓库踩过坑：PIL 的 LAB 转换不可靠，已改为自实现并自检）
python style-distill/analyze_style.py --selftest

# ② 量参考图组 —— 输出逐图 stats + 聚合
python style-distill/analyze_style.py <图片组目录> -o style-distill/distill_stats.json

# ③ 参照法证伪：把异风格参照图单独跑一遍，逐指标对比
python style-distill/analyze_style.py <异风格图目录> -o style-distill/foreign_stats.json
```

输出 JSON 的结构是 `{folder, per_image[], aggregate{}}`——**阈值从 `aggregate` 里取，逐图明细在 `per_image` 里**
（脚本同时会把关键值直接打印到控制台，抽样时看控制台更快）。
`aggregate` 里可直接当 B-6 阈值区间的字段：
`paper_white_ratio_mean` · `lum_p05_mean` · `lum_p95_mean` · `val_mean_content_mean` · `val_std_mean` ·
`sat_mean_content_mean` · `sat_p90_content_mean` · `contrast_range_mean` · `edge_density_mean` ·
`wash_ratio_mean` · `lab_b_mean_mean` · `hue_family_mean` · `palette_top10`（**仅描述性证据，不是迁移目标**）。
`per_image` 用来发现"哪张明显偏色/偏淡"，`aspect_all` 用来确认画幅是否统一。

> ⚠️ **口径警告（实测发现）**：`analyze_style.py` 第 198 行的留白掩膜阈值是 **0.94**，
> 而 `漫画风格蒸馏.md` 第 65 行同时给了两个口径（>0.97 → 42.5%；>0.94 → 51.0%），
> 第 236–245 行表里标着 ">0.97" 的 0.503/0.520 从数值看更接近 0.94 口径。
> **引用留白指标时必须写明口径**，否则"≥0.35"的达标线到底对哪个口径成立就说不清。

**改前先看明暗预览**（判断"抬暗部"这一档会造成多大损失，再决定用不用）：
```powershell
python style-distill/one_preview.py <目标图> --floor 0.40 -o tone_preview.png
```

## 4. 模式 C · 落地（把蒸馏结果用在一张具体图上）

1. **组装 prompt**：骨架照 `img2img_方案.md` 第 4 节（双段式：`PRESERVE` 锁内容 → `COLOUR LOCK` 锁色相 →
   `STYLE` 只讲渲染 → `DO NOT INCLUDE`），风格词取 B-4，负向取 B-5，档位取 B-8。
   中文接口版照 `style_prompt.md` 第 3 节。
2. **参数**：`{接口}` 是 edits 类 → 上传顺序在文本里点名、尺寸跟随目标图、负向用正文段替代；

3. **验收**（三条命令，顺序别调）：
```powershell
python style-distill/analyze_style.py <输出图目录> -o style-distill/new_stats.json   # 对照 B-6 区间
python style-distill/compare_identity.py <目标图> <输出图>                            # 身份漂移（发色/饰品/过曝）
python style-distill/preserve_hue.py --style-output <生成图> --original <目标图> -o <输出>  # 色相兜底
```
4. **失败回退**：身份漂移 → 缩短 STYLE 段、把 PRESERVE 提到第一句、靠 `compare_identity.py` 复验；
   背景被删 → 删掉负向里的背景清除词；过曝/过灰 → 检查是否 CFG 过高或负向缺 `dirty gray`。

> `preserve_hue.py` 的前提别忘：色相取自目标图**同位置**像素，生成图与原图几何位移大时会错位
> （实测过把参考图道具的红色错位糊到人体上）；位移很大时不适用。

## 5. 三个模式共用的四条纪律

1. **铁律 A**：只迁手法，不迁配色。参考图的 hex 只当描述性证据。
2. **只搬风格，不搬内容**：参考图有、目标图没有的东西一律不加。
3. **不编造**：作者、年代、模型、镜头、制作流程、**任何未经脚本实测的数字**。
4. **不恢复原始提示词、不复刻作者署名**（署名水印占画幅宽 2–3% 那种，迁移时不得复制）。

## 8. 已知边界

- **单图不能蒸馏**：同一风格内部饱和度跨度可达 0.032–0.148，抽一张就下结论必偏。
- **模型不能给数字**：B-6 的数值必须由 `analyze_style.py` 填；模型写的数字一律作废。
- **阈值必须证伪**：不经参照法验证的验收线等于没有验收线。
- **半风格项要显式决策**：留白、背景、画幅、明暗档位、署名——每一条都要写明"迁移后的效果"与"代价"，
  未声明前按"不迁移"处理。
- **不猜作者、不猜模型、不猜镜头、不声称恢复原始提示词、不复刻署名。**
- **提示词本体不含平台专属参数**：参数集中在模式 A 的 F 段与 `img2img_方案.md` 第 6 节。
- **本文件未做的事**：没有重跑任何生图、没有新增或修改任何脚本、没有改动上述任何既有文件
  （`git status` 只有本文件与 v2、评审两份新文件）。
