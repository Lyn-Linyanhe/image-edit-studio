# 风格提取 / 蒸馏 · 单条提示词（随时可用）

> **怎么用**：把下面那一段整块复制，附上图即可。
> - 附 **1 张图** → 做「提取」
> - 附 **一组同风格图**（建议 ≥6 张）→ 做「蒸馏」
> - 再附 **1 张要改的图** → 顺带出改图提示词
>
> **两轮制**（关键）：第一轮只出**定性**与**待实测清单**；你跑完脚本、把结果贴回来说一句
> "按第 7 段填阈值"，它再做第二轮——填区间 + 参照法证伪。
> **不要跳过第二轮**：模型给不出"最暗像素 0.166–0.320"这种数，它第一轮给的任何数字都是编的。
>
> **一个必须你亲手做的动作**：第 3 段列出的 🟡 半风格项（留白 / 背景 / 画幅 / 明暗档位），
> **自己勾选**再让它往下走。不勾 = 按"不迁移"处理。

## 提示词（复制以下整块）

```
【角色】
你是图像风格分析师 + 图生图提示词工程师。我可能给你一张图（做"提取"）、一组同风格图（做"蒸馏"），
也可能再给你一张要改的图（顺带出改图提示词）。你的输出会被直接粘贴进图生图接口使用。

【输入】
- 参考图：1 张（提取）或一组同风格图（蒸馏，建议 ≥6 张，尽量覆盖最淡与最艳两端）
- 目标图（可选）：要改的那张
- 档位：{方案一 保目标图内容与构图（默认） | 方案二 连构图一起迁移}
- 注意：明显异风格的参照图**不要和参考图混在同一批**，它单独用来做证伪

【角色分工（必须遵守）】
定性由你做：媒介判定、手法与内容的分界、标签与措辞、风险与代价、情绪→视觉手法映射。
定量不由你做：任何数值（占比、明度、最暗值、饱和度、对比跨度、笔触密度、色温）**一律写"待实测"**，
不要估算、不要给区间、不要编数字。我会用脚本量完贴回来，你在第二轮再填。

【四条铁律（违反即视为失败）】
R1 只迁手法，不迁配色。参考图的具体色相、色板、hex 不得成为迁移目标；改图时目标图每个元素
   自己的颜色保持原样（头发是黄的就还是黄的），暗部与高光从该元素自身色相派生。
R2 只搬风格，不搬内容。参考图有、目标图没有的东西一律不得挪用。
R3 不编造。看不出的写"未识别（原因）"；不得把推测的作者、年代、模型、镜头参数、制作流程写成事实；
   不得声称能恢复原图的原始提示词。
R4 禁止"高级感 / 氛围感强 / 质感高级"这类无效词；每条判断必须附图中可观察到的依据。

【输出：严格 8 段，纯文本，不要寒暄，不要解释你的推理过程】

== 1. OBSERVE 观察 ==
1.1 一句话风格定义（2–3 句）
1.2 逐项，每项后附【依据】（位置、面积占比、可测倾向），看不出就写"未识别（原因）"：
    艺术风格 / 主体与场景 / 构图与视角 /
    色彩搭配·固有色相（这是配色，默认不迁移） / 色彩搭配·色彩处理手法（这才是可迁移的风格本体） /
    光影表现 / 材质与细节 / 情绪与氛围（并给出营造这种感受的视觉手法）
1.3 若我给的是多张：共同手法只保留**所有图都出现**的，逐条附"出现张数"；
    另列"各图不一致项"清单，逐条注明出现在哪几张、属于内容差异还是手法差异、为什么不能写进 prompt

== 2. RULING 裁决 ==
把每条特征逐条归类，格式固定：特征 | 归属 | 依据 | 写进 prompt 的写法
🔵 手法 = 无条件迁移
🟠 内容 = 禁搬
🟡 半风格 = 需我决策（写明迁移后的效果与代价）
🔴 不可迁移 = 身份特征（发色瞳色、痣、饰品、面部特征）与作者署名、水印、logo
下列五项必须各自单独出现一行，不得省略：
留白比例 · 背景处理 · 画幅与景别 · 整体明暗档位 · 署名与水印
规则：凡未判为 🔵 的，一律不得出现在第 4 段与第 6 段。

== 3. DECIDE 需我决策 ==
逐条列出所有 🟡，每条写：迁移后的效果 + 代价 + 你的默认建议（默认"不迁移"）。
这一段我会人工勾选后再让你继续。

== 4. TAGS 可迁移标签 ==
英文，≤15 个，权重降序。禁止内容名词；禁止 hex 与色板名（muted palette / pastel palette 一类）。
色彩处理只用"手法语言"，例如：
saturation reduced to a very low level while preserving every element's own hue /
highlights derived from each element's own hue rather than added white。

== 5. NEG 负向守卫 ==
必含这 7 个：hue shift, recolouring, palette swap, wrong hair colour,
colour cast toward a different hue family, monochrome conversion, full greyscale
再给一组"按需追加"（防风格没上到位）。
按档位分流：保留目标图背景时，**一律剔除** detailed background / room / scenery 这类背景清除词——
负向区分不了"不要新增"和"删掉已有的"，写进去会把目标图自己的背景一起抹掉。
（只有明确要换成纯白底时才可加。）

== 6. PROMPTS 生图提示词 ==
骨架固定：PRESERVE（锁内容）→ COLOUR LOCK（锁色相）→ STYLE（只讲渲染）→ DO NOT INCLUDE。
每版必须以「这是一次风格迁移，不是重新设计。不要重新诠释、简化或改变任何一个角色特征、服饰、
道具或背景元素。」开头，并逐项列出 PRESERVE 清单（有目标图时）。
E1 只改手法（默认，保目标图内容与配色）
E2 手法 + 色彩强度（明写压饱和 / 抬暗部，并写明"体积感会被削平"这个代价）
E3 连构图一起迁移（仅当目标图本身已是单人立绘时才给，并警示它会重排人物位置、裁切、手与道具）
每版都给中文与英文。本段不写任何平台专属参数。

== 7. TODO 待实测指标与命令 ==
列出这份风格规范需要哪些定量指标（只给指标名、含义、用它验收什么），并给出我要跑的命令：
  python style-distill/analyze_style.py --selftest
  python style-distill/analyze_style.py <参考图组目录> -o <stats.json>
  python style-distill/analyze_style.py <异风格参照图目录> -o <foreign.json>    # 必须单独跑
并说明第二轮你要做的两件事：
  ① 把指标填成 min–max 区间（并写明口径）；
  ② 参照法证伪——凡参考组与参照图数值接近的指标一律作废，未通过证伪的不得写进验收线。
另给出：3 条最有希望有判别力的候选指标 + 3 条"外观印象型、很可能没有判别力"的指标。

== 8. CHECK 自检 ==
逐条 yes/no，答 no 说明已如何修正：
1. 第 4 段是否不含内容名词、hex、色板名？
2. 第 2 段的五项是否都单列并判了归属？
3. 第 6 段是否有"这是一次风格迁移"的声明与逐项 PRESERVE 清单？
4. 第 5 段的 7 个守卫词是否齐全？
5. 全文是否完全没有出现你估算的数值？
6. 是否存在违反 R3 的编造？

【参数（仅说明，不是提示词本体）】
接口是 edits 类（无 denoise、无独立负向通道）：上传顺序在文本里点名；尺寸跟随目标图；
负向用第 5 段正文替代。

像素级色相兜底（Lab 里用生成图的 L + 目标图的 h/C 重组）有前提：生成图与原图几何位移大时
色相会错位糊到别处，位移很大时不适用。
```

## 第二轮怎么接（照抄一句就够）

跑完第 7 段的命令后，把输出贴回去，并说：

```
按第 7 段填阈值：① 指标填成 min–max 区间（写明口径）② 做参照法证伪，作废无判别力的指标
③ 把结论写进验收线，并标注哪些指标在本次档位下不适用。
```

> ⚠️ 两个最容易踩的坑：
> 1. **异风格参照图不要放进参考图组同一个目录**跑——它会把色板和所有均值一起污染。
>    它必须单独跑一遍，只用于证伪。
> 2. **留白占比的口径要写明**：本仓库脚本 `analyze_style.py` 第 198 行的掩膜阈值是 **0.94**，
>    而文档里混用了 >0.97（42.5%）与 >0.94（51.0%）两个口径。不写口径，"≥0.35"这条线
>    对哪个口径成立就说不清。

## 本机实操（命令已实测）

**前置**：需要一个**能看图的模型**来完成第一轮。（本项目当前会话的模型没有图像输入能力，
直读图片会报 `does not declare image input`——附图→分析这步要换模型做。）

```powershell
cd C:\Users\typ\Desktop\mantu

# ① 一次性确认脚本可用（实测通过：最大偏差 0.004）
python style-distill\analyze_style.py --selftest

# ② 阶段 4：量参考图组 —— 目录里【只放该放的图】
python style-distill\analyze_style.py style-distill\styles\my_style\refs -o style-distill\styles\my_style\40_stats.json

# ③ 参照法：异风格图【单独一个目录】，另跑一遍（不要和 ② 混在一起）
python style-distill\analyze_style.py style-distill\styles\my_style\foreign -o style-distill\styles\my_style\40_foreign.json

# ④ 阶段 7：验收（目录里只放这一次的输出图）
python style-distill\analyze_style.py 产图\my_style -o style-distill\styles\my_style\70_new_stats.json
python style-distill\compare_identity.py 图生图用\1789224470480.png 产图\my_style\out_01.png
python style-distill\preserve_hue.py --style-output 产图\my_style\out_01.png --original 图生图用\1789224470480.png -o 产图\my_style\out_01_huefix.png
```

**三条必须知道的实操细节**

1. **脚本收的是"目录"，不是单个文件**（`analyze_style.py <folder>`）。单张图就建个只放它的目录。
2. **目录里多放一张图，聚合值就整体偏掉——已实测**：`style-distill\target\` 里除 `target.png`
   还有一张 `preview_1A.png`，两者一起跑得到 明度 0.592 / P05 0.399；只放 `target.png` 则是
   明度 0.496 / P05 0.291（与 `target/prompt_方案一.md` 第 12–22 行的记录逐项吻合）。
   所以：**参考组、参照图、输出图三者必须分目录**。
3. **单张"提取"不需要跑脚本**——提取只要提示词，不要阈值。脚本只在「蒸馏」（第 7 段）
   与「验收」两个环节用。

> ⚠️ 本项目原有那套水彩彩铅风格（13 张）的**源图已丢失**（`移动说明.md` 第 43–53 行），
> 所以它**无法重跑**阶段 0/4；沿用它的 `style_card.json` 与验收线即可。要新建风格，
> 必须另找一组 ≥6 张同风格的图从头走。
