# 漫画风格蒸馏报告

**样本**：`<工作区>` 下 13 张 JPG，全部 **1200×1600 px（3:4 竖幅）**。
**方法**：13 张全部逐张目视拆解 + 脚本量化（`analyze_style.py` / `darkness_check.py` / `accent_check.py` / `blush_check.py`），
原始数据见 `style_stats.json`、`darkness_check.json`。
**用途**：作为「把其他图片改成这一风格」的风格锚点（prompt 见 `style_prompt.md`，结构化卡片见 `style_card.json`，
迁移方案见 `img2img_方案.md`）。

> ### ⚠️ 铁律 A · 只迁移手法，不迁移配色
>
> **目标图里每个元素自己的颜色一律不动**：目标图头发是黄色就保持黄色，**不会因为基准图是红色就变红**，
> 也不会因为基准图是银灰/灰紫就被漂成银灰——除非明确声明要换某个元素的颜色。
>
> 边界来自你给的 7 维度框架：「主色/辅助色」是**配色**（不迁移），「饱和度/对比度/明暗关系」是**手法**（迁移）。
> 所以本文档第 4 节那 10 个色值**只是"饱和度 0.085"这一手法的外观证据，不是迁移目标**；
> 腮红 `#F4D7DA`、暗部灰紫、高光纸白同理——改图时一律改为**从目标图各元素自身色相派生**。
>
> 详见 `img2img_方案.md` 第 0 节与第 8 节（`preserve_hue.py` 是这一条的像素级兜底）。

## 0. 一句话风格定义

> **高调、极低饱和的水彩彩铅手绘日系插画**：纯白纸上一个蓬松长发少女的居中学生半身像，
> 抱着书本或文件夹，视线落在画外，铅笔断线勾出轮廓，水彩极淡晕染上色，画面里没有黑色，也没有重阴影。

关键判定：这是**模拟传统媒材的数字插画（水彩 + 彩铅 + 铅笔线稿）**，不是 3D 渲染、不是厚涂 CG、不是赛璐璐平涂。
13 张为同一作者、同一系列，风格高度统一（可视为一个 IP 的定妆图组）。

## 1. 艺术风格

| 维度 | 判定 | 证据 |
|---|---|---|
| 大类 | 日系动漫插画（少女胸像/半身像立绘） | 13/13 一致 |
| 媒材模拟 | **水彩淡涂 + 彩铅/铅笔线稿**（数字作画，模拟传统纸绘） | 内容像素中 72% 属"极浅近中性"着色（S<0.12），呈水彩洗笔特征 |
| 完成度控制 | **故意保留草稿感**：轮廓线断续、收笔出锋、局部线稿未擦净、色块溢出线外 | 逐张可见；8B23 白衣处有明显扫笔擦痕 |
| 渲染手法 | 无体积渲染、无环境光遮蔽；靠**线稿结构 + 淡色分层**塑造，而非阴影 | 亮度 p95−p05 仅 0.471，对比度极低 |
| 与赛璐璐的区别 | 色块边界**模糊、渗染**，无硬边大色块（唯一硬边是笔记本封面） | — |
| 数字水印 | 画面左下/右下角有极小的作者中文署名（约占画幅宽 2–3%，浅灰细字） | 迁移时**建议不复制**署名 |

## 2. 主体与场景

- **主体**：单名年轻女性，学生/白领气质，年龄感 16–24。13/13 全为单人居中，无配角、无群像。
- **发型**（强特征）：**长发且发量蓬松凌乱**，碎发飞扬、发梢外翻。
  - 造型变体：松马尾+缎带蝴蝶结、低马尾、双丸子头、高马尾、披发、短发
  - 发色：银灰、灰紫、墨灰、蓝紫、深石墨——**全是低饱和的灰调**，无金发、无鲜艳染发
  - 实测全组发色均值 **#AAA6B1**（灰紫中灰，明度 0.50–0.76）→ 即使"深色头发"也只是中灰，不是黑
- **服饰**：针织高领毛衣 / oversize 开衫 / 白衬衫 / 西装外套 / 水手服 / 露肩 T 恤 / 黑色高领。
  一律**素色大块面，无印花无图案**（唯一装饰是笔记本封面上的小矩形标签）。
- **道具**（构图的核心配件，13/13 都有）：笔记本、文件夹、信封、铅笔、圆框眼镜、复古拨号电话、蛋糕、棒棒糖。
  母题 = **学业 / 办公室 / 校园**。
- **动作**：手部永远在画面内并占据胸前区域——抱书夹在胸前、扶眼镜框、托腮、笔抵下巴、双手捏信封。
  **手 + 道具 + 胸像构成稳定的三角/矩形结构**，这是本风格构图骨架，不是可选装饰。
- **场景**：**无场景**。纯白纸底，没有房间、没有家具、没有环境元素。个别图有道具（电话、蛋糕）但仍在白底上悬浮。

## 3. 构图与视角

- **画幅**：3:4 竖幅（1200×1600），13/13 完全一致。
- **景别**：胸像 / 半身像。头顶距上缘约 3–8%，下缘裁切在腰/髋部，**不做全身**。
- **主体位置**：绝对居中；脸部位于画幅**上半部中央偏上**（约纵向 1/3 处），面部朝向一侧。
- **角度**：接近平视，带轻微仰俯；**头部倾角 10–20°**，肩线倾斜，几乎不做正面正脸平视。
  - 侧身回眸（47EC）、侧脸 3/4（多数）、微俯视（EB7D 低头）
- **留白**：**纯白占画布 42.5%**（三通道 >0.97）；按纸白阈值（>0.94）算占 **51.0%**。
  留白集中在四角与主体轮廓外，**不使用背景色块或渐变**。留白即背景。
- **空间层次**：几乎无景深（无透视、无前景/背景分离），层次完全由**线稿遮挡关系 + 淡色叠压**表达。
- **视线方向**：13 张中约 8 张望向画外（画面左或右上/下），5 张与观者对视；其中 2 张是单眼 wink（A290、E2E3）。

## 4. 色彩搭配

### 整组主色板（OKLab k-means，全组 10 色，按面积占比）

| 色值 | 占比 | 明度 | 角色 |
|---|---|---|---|
| `#F2EBED` | 14.1% | 0.93 | 纸白 / 高光 / 白衬衫 |
| `#E3DEE3` | 12.8% | 0.88 | 浅灰底 / 肌肤过渡 |
| `#D5CFD6` | 11.4% | 0.82 | 浅灰紫（发梢、布料受光面） |
| `#C3BFC3` | 10.6% | 0.76 | 中性浅灰（布料中间调） |
| `#A3A0AB` | 10.5% | 0.63 | 灰紫（头发主体、阴影灰） |
| `#B3B0B7` | 10.1% | 0.70 | 中性灰紫 |
| `#9190A1` | 10.1% | 0.57 | 蓝灰（外套、文件夹） |
| `#857F93` | 8.9% | 0.51 | 灰紫深调（发底、暗部） |
| `#787084` | 7.3% | 0.45 | 深灰紫 |
| `#635B70` | 4.1% | 0.37 | **全组最深调**（暗部极限） |

**结论**：色板是**一条从纸白到深灰紫的连续灰阶**，而不是若干鲜艳色的组合。整组最深色是 `#635B70`——
**画面里没有黑色。**

### 量化色彩指标（内容像素，剔除纸白）

| 指标 | 实测 | 含义 |
|---|---|---|
| 饱和度均值 | **0.085** | 极低。**但该指标不具判别力**，见 10.2 |
| 饱和度 P90 | **0.140** | 90% 的像素饱和度不到 0.14 |
| 明度均值 | **0.744** | 高调，整体偏亮 |
| 明度标准差 | **0.147** | 层次压缩，明暗跨度小 |
| 亮度 P05 / P95 | 0.523 / 0.995 | 暗部极浅 |
| 亮度 P95−P05（对比度） | **0.471** | 低对比 |
| 最暗像素（13 张范围） | **0.166 – 0.320** | 12/13 张最暗 ≥ 0.227 |
| 亮度 <0.20 的像素占比 | **0.0001%**（12/13 张为 0） | **实质上没有暗部** |
| 色相家族占比 | 紫罗兰 28% · 蓝 27% · 红粉 20% · 绿 9% | 冷暖：**冷灰紫**为骨、暖粉为点 |
| 色温 a\* / b\*（CIE Lab，内容像素均值） | **a\* = +3.74**、**b\* = −4.42** | 整体**轻微偏冷**、略偏红。冷暖差异主要由色板分支决定：A 组 b\* +1.61（唯一微暖）、B 组 −7.96、C 组 −8.42（偏冷） |

> **修正记录**：初版曾据 PIL `convert("LAB")` 得出"整体偏暖 b\*=+25.25"，该数值**无效**——实测 PIL 的 LAB 转换对 a\*/b\* 处理不可靠
> （纯白得 a\*=b\*=−128，纯红得 (a\*,b\*)=(−47,−58) 而正确值约 (+80,+67)，两个近乎相同的近白像素给出 A=0 与 A=255）。
> 现改为自实现 CIE Lab(D65)，并以标准参考值自检（`analyze_style.py --selftest`，最大偏差 0.004）。

### 三套色板变体（13 张实为同一风格的三个配色分支）

**A · 鼠尾草米白（5 张：187D、1A37、47EC、C8BE、EB7D）**
- 主色：`#F0E9E6` / `#DAD3D4` / `#BAB7B2` / `#9FA09B` / `#7D7C77`
- 特征：**饱和度均值仅 0.032–0.045，100% 内容像素 S<0.12**——肉眼读作"鼠尾草绿"，实测几乎是中性灰，
  绿色仅存于色相（绿相占比 13–34%）而非饱和度。这是本风格最"淡"的一支。

**B · 薰衣草灰紫（4 张：32A9、8B23、A290、FD7A）**
- 主色：`#E4DAE7` / `#C2B9D0` / `#A89DBA` / `#877A96` / `#6A607F`（深调 `#584F64`）
- 紫罗兰色相占比 73–98%，饱和度 0.079–0.148。FD7A（黑高领+紫西装）是全组最深、最沉的一张。

**C · 藏青石墨（4 张：57A8、78A4、B325、E2E3）**
- 主色：`#E5E5F0` / `#CCCCDB` / `#ABACBB` / `#8C90A3` / `#696775`
- 蓝色相占比 81–96%，饱和度 0.101–0.131。8B23（全白西装）可视为本支的"零彩度极限"。

### 两个信号色（全组唯一允许的暖色）

- **腮红 / 唇色**：均值 **`#F4D7DA`**，饱和度仅 **0.103–0.149**，明度 0.92–0.98。
  → 是"极柔的奶粉色"，不是鲜艳的粉红。13/13 张存在，是本风格最强的情感符号。
- **高饱和暖粉点缀**：**13 张里只有 2 张出现**，且面积仅占画布 0.39%–1.05%：
  红电话 `#AB737E`（78A4）、草莓 `#ED9AA8`（E2E3）。
  → 用法是**"整幅灰调里点一个暖色小道具"**，绝不是大面积上色。

## 5. 光影表现

- **光源**：单一柔和散射光，来自**正面偏上方**（约头顶 45°），无明确射向。
- **光质**：极软。没有硬边投影、没有镜面高光、没有体积光/光束/光晕。
- **明暗关系**：**压缩到极限**。暗部最深处 0.37 明度，亮部到纯白，
  但 P05–P95 跨度只有 0.471——相当于只有"白 → 浅灰 → 中灰"三层。
- **投影**：**画面里没有落地投影，也没有主体投在白纸上的影子**。主体边缘靠线稿收边，直接"贴"在纸白上。
- **高光处理**：头发高光用**留白 + 浅色笔触提亮**（不是白色涂抹），呈丝状的洗笔痕。
- **特殊光效**：无。唯一近似"光效"的是瞳孔内的小高光点与头发的丝状亮部。
- **关键红线**：**不允许出现黑、不允许出现深阴影、不允许出现彩色环境光**。

## 6. 材质与细节

- **线稿**：铅笔/细笔触，**断续、粗细有变化、收笔出锋**，轮廓线不完全闭合，有叠线重描（草稿感）。
  全组最暗线条是 **深灰紫/暖灰**（`#4E455A` ~ `#74716F`），**不是纯黑线**。
- **上色**：
  - 水彩洗笔式淡涂，色块边界**模糊、渗染、偶尔溢出线外**
  - 有明显的**擦痕/扫笔**（8B23 白西装、EB7D 绿开衫下摆最明显）
  - 大面积"留白当色"，靠纸白承担高光与亮部
- **头发质感**：**成束的扫笔**而非逐根描线，蓬松杂乱，发梢分叉外翘；碎发用极细的单根线勾出。
- **皮肤**：平涂 + 极浅过渡，脸颊与鼻尖一层柔粉晕染，**眼下有小痣/雀斑**（多张可见，是人物识别点）。
- **眼睛**：大眼、浓密分束的上翘睫毛、瞳孔带渐变与细小星状高光、眼白面积小、眼型微下垂。
- **布料**：褶皱只用**少量淡笔触暗示**，不做细密布纹；无图案、无印花、无金属反光（手表/皮带扣是唯一例外）。
- **笔触/细节密度**（Sobel 梯度均值）：全组 **1.99 – 3.58**，均值 2.89。
  该值主要由**碎发数量**驱动，而不是线稿粗细：8B23（大块纯白衣）最低 1.99，EB7D（碎发密集）最高 3.58。
- **画面清晰度**：整体"柔"，边缘不锐利；无噪点、无胶片颗粒、无纹理贴图。

## 7. 情绪与氛围

- **主导情绪**：安静、温柔、内敛、略带忧郁与眷恋的**书卷气**。不激烈、不甜腻、不性感化。
- **营造手法（逐条对应到画面元素）**：

| 情绪目标 | 视觉手法 |
|---|---|
| 安静 / 空 | 纯白留白 42.5%，无场景无背景 |
| 温柔 / 呼吸感 | 极低饱和（0.085）+ 高调明度（0.744）+ 低对比（0.471） |
| 手绘温度 | 铅笔断线、水彩渗染、扫笔擦痕 |
| 少女感 / 无攻击性 | 大眼 + 浓密睫毛 + 柔粉腮红（`#F4D7DA`）+ 眼下小痣 |
| 疏离 / 心事 | 8/13 张视线落在画外；侧身与头部倾角 10–20° |
| 轻微叙事钩子 | 单件道具（信封、红电话、蛋糕、棒棒糖）暗示一个未说出的情境 |
| 不沉重 | 画面没有任何黑色与深阴影 |

- **禁区**：不要做成"暗黑/哥特"、"赛博霓虹"、"浓艳少女漫"、"治愈系高饱和糖果色"。本风格的温柔来自**低饱和**，不是来自亮色。

## 8. 约束（红线）

### 8.1 迁移到其他图片时必须遵守（手法层，受铁律 A 约束）

1. **固有色相一律不动**：目标图每个元素自己的颜色保持原样，不做调色板替换、不往灰紫或蓝灰靠。
2. **不要黑色**：最暗值不低于明度 0.30，暗部**抬亮**——但暗部色相用**该元素自身色相压暗去饱和**，
   ❌ 不是统一换成 `#635B70` / `#787084`（那 13 张的灰紫是**它们自己**的固有色，不是通用规则）。
3. **不要深阴影**：无落地投影、无戏剧性明暗；明暗跨度 ≤ 约 0.5。
4. **必须保留铅笔断线与水彩渗染**：不能磨成干净利落的赛璐璐或厚涂。
5. **高光从自身色相提亮**，❌ 不是统一加白或留纸白。
6. **腮红用低透明度柔粉晕染，色调从目标图肤色自身派生**，❌ 不是写死 `#F4D7DA`。
7. **不要复制原作者署名**。
8. **饱和度压到约 0.085 属于手法层**（可迁移），但它与"色彩不动"存在张力——
   要完全保留目标图的色彩语言，就把这一条降级（见 `img2img_方案.md` 的 1B 与 `--sat-scale`）。

### 8.2 仅"复刻参考图本身"时才适用（文生图 / 方案二）

以下几条描述的是**这 13 张作为作品本身**长什么样，不是可迁移的通用规则：

- 背景必须是纯白纸，无渐变/色块/场景/粒子光斑
- 3:4 竖幅、单人半身、居中；不做全身、多人群像、横构图
- 手与道具必须入画（抱书/扶眼镜/托腮/笔抵下巴）
- 不加饰品堆砌（耳饰、手表至多各一件）
- 饱和度上限 ~0.15，唯一例外是占画布 <1.5% 的暖色道具

- 服饰（针织/衬衫/西装/水手服/oversize，素色）

- 动作（抱、托腮、扶眼镜、笔抵下巴、捏信封）

### 10.1 只换风格、保留原图构图（图生图）
- 先用 ControlNet（`lineart` 或 `softedge`，权重 0.6–0.8）锁住原图结构，再走 img2img。
- Denoise 建议：
  - 原图**已是插画/线稿** → **0.35–0.50**（只换笔触与配色，保住造型）
  - 原图是**照片/写实图** → **0.55–0.75**（需要重绘五官与发丝才像手绘）
  - 想整张重生 → 0.75–0.85，但此时构图基本丢失，需重新给构图描述
- 风格锚定：把 2–3 张参考图交给 IPAdapter / 风格 LoRA / 参考图 conditioning，配合 `style_prompt.md` 的提示词。
- CFG 建议 5–7（偏低，避免模型把画面对比度拉高）。

### 10.2 验收清单（改完逐条核对）

**先说一个实测出来的坑**：把 13 张之一的 `187DAF…`、`FD7AB5…`，和一张**完全不同风格**的图（`compose/style_ref.png`，
带深色场景背景的柔和厚涂插画）一起送进 `analyze_style.py`，结果是——

| 指标 | 187DAF（本风格） | FD7AB5（本风格） | style_ref（异风格） | 判别力 |
|---|---|---|---|---|
| 纯白(>0.97) 占比 | 0.503 | 0.520 | **0.006** | ★★★ |
| 亮度 P05（最暗基准） | 0.579 | 0.387 | **0.291** | ★★★ |
| 内容明度均值 | 0.770 | 0.603 | 0.496 | ★★ |
| 内容饱和度均值 | 0.035 | 0.144 | 0.077 | **无** |
| 笔触密度 | 3.06 | 2.46 | 1.98 | ★ 弱 |
| b\* 色温 | +1.98 | −9.66 | +3.67 | **无** |

**结论**：**"低饱和"根本不是这套风格的判别特征**——异风格那张的饱和度（0.077）夹在本风格两张（0.035 / 0.144）中间。
同理 b\*、笔触密度都没有判别力。真正能把它和别的风格分开的是：

1. **纯白留白占比**（本风格 0.446–0.624；异风格 0.006——差 80 倍，最硬的指标）
2. **最暗值下限**（亮度 P05 0.387–0.616，且全图无 <0.20 的像素）
3. **整体明度偏高**（内容明度 ≥ 0.60）

**所以按这三条硬指标验收，不要按"看起来低饱和"验收：**

- [ ] **纯白(>0.97 三通道)占比 ≥ 0.35**
- [ ] **亮度 P05 ≥ 0.35**，且最暗像素明度 ≥ 0.15（本风格实测最暗 0.166–0.320）
- [ ] **内容区域明度均值 ≥ 0.60**
- [ ] 画面里找不到黑（肉眼复核：12/13 张亮度 <0.20 的像素占比为 0）
- [ ] 背景无任何颜色/渐变/元素
- [ ] 线稿有断线与叠加重描，不是干净闭合线
- [ ] 色块边界有水彩渗染与外溢，不是硬边平涂
- [ ] 腮红是"奶粉色"（S 0.10–0.15），不是亮粉
- [ ] 手与道具在画面内
- [ ] 3:4 竖幅、单人、半身、居中（仅在方案二下要求）
- [ ] 内容饱和度 ≤ 0.15（**辅助项，不作为判别依据**）

> 上机验证：`python style-distill/analyze_style.py <新图目录> -o style-distill/new_stats.json`，
> 把输出与本文第 4 节指标对照即可。
