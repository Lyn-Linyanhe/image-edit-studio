# 开源工具与项目在风格蒸馏流程中的应用

> 2026-10-06 调研→接入→验证的完整记录。背景：画风验收长期依赖肉眼（「像不像」「驳杂不驳杂」），
> 历史上多次因肉眼误判返工。本轮系统性搜索 GitHub 开源生态，按「能否提供肉眼给不出的增量」筛选接入。

## 一、已接入并验证（3 项）

### 1. wdtagger — 动漫图自动打标

- **来源**：<https://pypi.org/project/wdtagger>（SmilingWolf WD14 系，ONNX 模型源
  [deepghs/wd14_tagger_with_embeddings](https://huggingface.co/deepghs/wd14_tagger_with_embeddings)）
- **接入方式**：`pip install wdtagger`（依赖 onnxruntime 1.28，Python 3.14 兼容；模型经
  `HF_ENDPOINT=https://hf-mirror.com` 下载，374 MB，CPU 推理）
- **验证数据**：图一 vs 产出对比，tag 重合率 0.386–0.556；「仅模板／仅产出」清单能精确暴露
  内容差异（如 `oil-paper_umbrella` vs `closed_umbrella`——伞的形制变化被自动捕捉）
- **在流程中的位置**：`scripts/style_metrics.py`——生成后体检第 6 步，为定性分析提供可复核的
  客观底稿，替代「靠肉眼列特征」（撑伞任务早期「提取没做好」的根源）

### 2. colorgram.py — 调色板量化

- **来源**：<https://pypi.org/project/colorgram.py>（纯 Python，几十 KB）
- **验证数据**：跨季节场景（夏日模板 vs 雪景/月夜产出）主色号差 <0.01 可证色彩气质保真；
  **判读规则**：跨内容对比时按「亮区色」判读（夜景整体必然压暗，人物亮区色号才是画风指标）
- **在流程中的位置**：`style_metrics.py`——色彩气质验收，替代肉眼「像不像」

### 3. controlnet-aux — Lineart 线稿提取（含证伪记录）

- **来源**：<https://github.com/lllyasviel/ControlNet> 的独立 pip 包
  `pip install controlnet-aux`（0.0.10；依赖 CPU 版 torch 约 200 MB——Windows pip 默认即 CPU 版）
- **验证结果**：
  - ✅ **LineartDetector**：对图一提取质量好（轮廓/伞骨/衣褶/发丝全出）；三图线稿并排能把
    「用笔驳杂」直接可视化（模板长曲线 vs 产出短碎线一目了然）——接入 LINE 段分析与验收对照
  - ❌ **OpenposeDetector**：对动漫立绘失效（真人照片训练，只检出一段手臂，躯干头腿全丢）
  - ❌ **DWposeDetector**：mmpose 依赖 bug＋Python 3.14 无法安装全家桶
- **结论**：姿态客观化对动漫立绘**当前无解**（真人系模型已证伪），POSE 段继续人眼＋几何锚点；
  待动漫特化姿态模型出现再验
- **在流程中的位置**：生成后体检「Lineart 对照查噪」步骤——噪声碎点/驳杂在线稿上呈短碎线

| 项目 | 是什么 | 启用条件 |
|---|---|---|
| [JoyCaption](https://github.com/fpgaminer/joycaption) | 开源动漫图描述 VLM | WD14 标签＋人工观察不够用时；本地跑需大模型推理 |

## 三、调研后判定不适用

| 方向 | 判定理由 |
|---|---|
| AI 生成图检测器（[lynote-ai/ai-image-detector](https://github.com/lynote-ai/ai-image-detector)、AniPrO 等） | 回答「这张图是不是 AI 画的」——我们的需求是「定位哪个区域有 AI 味」，方向相反；且实测高频占比一维指标对「AI 味」无判别力（产出 4.94% 反低于模板 9.37%——AI 味是结构质变不是能量量变） |
| Claude/Agent Skills 生态（[anthropics/skills](https://github.com/anthropics/skills)、awesome 列表） | 无现成图像风格蒸馏 skill；自研 style-distill 反而领先，借鉴其 SKILL.md 规范即可 |
| ComfyUI 本地部署 | 用户排除；且 `input_fidelity=low`（闭源 API 原生参数）已解决同等问题 |

## 四、接入后的验收体系（style_metrics.py）

```text
python scripts/style_metrics.py <模板图> <产出图>
# 输出：两图各 8 色调色板（hex＋占比）＋ WD14 标签（共同/仅模板/仅产出/重合率）
```

**判读规则（2026-10-06 实测确立）**：
1. 重合率与内容发散度正相关（同内容族 0.46 → 雪景 0.41 → 夜景 0.23）——看「差异清单是否合理」，不看绝对值；
2. 跨内容（季节/时辰）对比按**亮区色**判读（夜景整体必然压暗）；
3. WD14 的 tag 是模型输出，只作客观底稿，不替代人工核验（R3）。

## 五、依赖清单汇总

```text
pip install wdtagger colorgram.py          # 打标＋调色板（onnxruntime 自动安装，CPU 可跑）
pip install controlnet-aux                 # Lineart（依赖 CPU 版 torch，Windows pip 默认即 CPU 版）
export HF_ENDPOINT=https://hf-mirror.com   # 模型下载走国内镜像
```

模型缓存约 400 MB（Lineart 33 MB＋WD14 374 MB），全部 CPU 推理，无 GPU 要求。
